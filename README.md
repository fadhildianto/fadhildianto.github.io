# Portofolio Fadhildianto — GitHub Pages

Portofolio personal berbahasa Indonesia dengan fokus pada pengalaman, keahlian, dan proyek di bidang sistem informasi dan teknologi.

## Menjalankan secara lokal

Tidak membutuhkan Laravel, Laragon, npm, atau database.

1. Extract folder.
2. Buka `index.html` di browser, atau gunakan extension Live Server di VS Code.

## Menayangkan di GitHub Pages

1. Buat repository bernama `USERNAME.github.io`.
2. Upload seluruh isi folder ini ke root repository.
3. Buka Settings → Pages.
4. Pilih Deploy from a branch → `main` → `/ (root)`.
5. Simpan dan tunggu deployment.

## Bagian yang perlu diganti

- `assets/images/profile-placeholder.svg` → ganti dengan foto profil asli.
- `assets/images/project-sistem-informasi.svg` → ganti dengan screenshot sistem.
- `assets/images/project-peta.svg` → ganti dengan screenshot peta.
- `assets/docs/CV-Fadhildianto.pdf` → ganti dengan CV versi terbaru bila diperlukan.
- Tautan GitHub/LinkedIn dapat ditambahkan pada bagian kontak jika URL profil sudah tersedia.

## Catatan konten

Portfolio ini tidak menonjolkan latar belakang SMK/TKJ atau pengalaman Alpha-M. Fokus utama diletakkan pada keahlian dan pengalaman yang paling relevan saat ini, terutama analisis sistem, perancangan basis data, implementasi sistem informasi, pengelolaan informasi, visualisasi, pengujian, dan dukungan operasional.
